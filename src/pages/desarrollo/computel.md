<span class="text-primary font-bold">
  Catálogo Tecnológico con Seguridad, Experiencia de Usuario Optimizada y Rendimiento de Alto Nivel
</span>

**Contexto:**
Tras un ataque cibernético que comprometió el sitio anterior, este proyecto nació como una solución integral: reconstruir desde cero con WordPress, priorizando **seguridad, rendimiento y funcionalidad**. En una nueva etapa de desarrollo, se realizaron mejoras adicionales enfocadas en optimizar aún más el rendimiento y la eficiencia del sitio.

**Soluciones implementadas:**

- Sistema de búsqueda avanzado: Filtrado por categorías y productos, superando al anterior en usabilidad.
- **Flujo de compra personalizado**: El carrito se registra en la web, pero la compra se finaliza por WhatsApp, adaptándose al modelo de negocio del cliente.
- **Gestión de usuarios con beneficios**: Registro personalizado para clientes y un **rol exclusivo para "reparadores"**, con descuentos automáticos en productos.
- **Optimización de rendimiento** (Frontend): Análisis y refactorización de estilos (CSS) y scripts (JS) para cargar solo lo necesario en cada página, reduciendo peticiones y mejorando tiempos de respuesta.
- **Limpieza y optimización de base de datos**: Al ser un catalogo de productos se buscó que no se relentice ni se llene la base de datos.
- **Optimización de plugins**: auditoría y configuración de los críticos para evitar cuellos de botella.
- **Migración y configuración de ImageKit.io**: Implementación del servicio para el alojamiento y entrega de imágenes, configurando la transformación y optimización automática de las mismas para todo el catálogo. Esto para **alivianar la web y el hosting** donde se aloja.

**Enfoque clave:**

- *Seguridad reforzada:* Desde la instalación limpia de WordPress hasta la implementación de protocolos de protección contra malware.

**Resultado:**
Un catálogo tecnológico **autogestionable, seguro y eficiente**, que simplifica la experiencia tanto para el cliente final como para el equipo interno.

_Es un sitio de un cliente habitual, al que incorporamos funcionalidades y realizamos mantenimiento según sus necesidades._
